# Simple Interest Calculator

A lightweight and responsive **Simple Interest Calculator** web application built using HTML, CSS, and JavaScript. This tool helps users quickly calculate simple interest on loans or investments without compounding.

---

## 🚀 Features

* **Real-time Calculation:** Computes simple interest instantly based on user inputs.
* **Clean & Responsive UI:** Designed with modern CSS for a clean, user-friendly layout.
* **Input Validation:** Handles missing or default values smoothly.
* **Formula Display:** Clearly shows the mathematical formula used for the calculation.

---

## 🧮 Mathematical Formula

The calculator uses the standard simple interest formula:

\[\text{Simple Interest (SI)} = \frac{P \times R \times T}{100}\]

Where:
* **P** = Principal Amount (Initial investment or loan amount)
* **R** = Annual Rate of Interest (in percentage)
* **T** = Time Period (in years, months, or days)
* **Total Amount** = P + SI

## 🏃 How to Run the Project

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```
2. **Navigate to the project directory:**
   ```bash
   cd Simple-Interest-Calculator
   ```
3. **Open the application:**
   * Double-click `index.html`
   * *Or* open it directly in any modern web browser (Chrome, Firefox, Edge, Safari).

---

## 📌 Usage Instructions

1. Enter the **Principal Amount ($P$)** in the designated input field.
2. Enter the **Annual Interest Rate ($R$)**.
3. Enter the **Time Period ($T$)** (years/months).
4. Click the **Calculate** button to view the interest and total amount.
